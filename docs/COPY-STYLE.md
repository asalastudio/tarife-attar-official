# Copy style

Jordan requires no em dashes in website or marketing copy. Use clear sentences, commas, colons or parentheses according to meaning. Apply this to metadata, navigation, product descriptions, quiz copy, journal content, chat replies, emails and social captions.

Use the Humanizer skill for written copy. Preserve URLs, identifiers and technical syntax. Review CMS and Shopify content separately from repository strings. A code change or prepared content patch is not proof of live publication.
