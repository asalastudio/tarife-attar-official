# Technical Documentation

Engineering and operations docs for the Tarife Attär site. Marketing assets (brand voice, catalog, channel copy) live in [`marketing/`](../marketing/README.md).

| Directory | Contents |
|---|---|
| [`setup/`](setup/) | One-time configuration: environment variables, Vercel, Sanity Studio, webhooks, Shopify tokens and checkout redirects, placeholder images, deploy checklists. |
| [`guides/`](guides/) | Ongoing how-tos and architecture: Sanity architecture and frontend integration, Sanity ↔ Shopify sync, SKU sync, product description sync, previews, metafields, hero backgrounds, animation system, Eleanor KB integration, troubleshooting. |
| [`reports/`](reports/) | Point-in-time documents: code and site audits, fix summaries (cache, Omnisend 404, Shopify connection, schema sync), verifications, and proposals (customer service portal). Historical record — check dates before acting on them. |
